# Bootstrap 5 Exercises

## Overview
This module covers Bootstrap 5 fundamentals including responsive layouts, grid systems, typography, forms, buttons, navigation components, cards, utility classes, icons, JavaScript plugins, and Sass customization.

## Topics Covered

- Bootstrap Setup (CDN & Local)
- Grid System & Responsive Layouts
- Flexbox Utilities
- Typography
- Forms & Input Components
- Buttons & Button Groups
- Navigation & Navbars
- Cards & Media Objects
- Spacing Utilities
- Colors & Backgrounds
- Display & Visibility
- Borders, Shadows & Positioning
- Bootstrap Icons
- Modal & Accordion Components
- Sass Customization

## Key Learning Outcomes

- Built responsive web layouts using Bootstrap Grid.
- Created reusable UI components.
- Applied utility-first styling.
- Implemented interactive Bootstrap components.
- Customized Bootstrap using Sass variables.
