# CSS3 Exercises – Community Event Portal

## Overview

This module demonstrates the application of CSS3 concepts through a single evolving project: **Local Community Event Portal**.

## Concepts Covered

- CSS Inclusion Methods
- CSS Syntax & Comments
- Selectors
- Colors & Backgrounds
- Typography
- Links & Lists
- Tables
- Box Model
- Multi-Column Layout
- Responsive Design
- CSS Debugging

## Features Implemented

- Modern UI Design
- Gradient Header
- Navigation Menu
- Event Listings
- Event Schedule Table
- Multi-Column News Section
- Responsive Layout
- Professional Typography

## Learning Outcomes

- Applied CSS styling techniques.
- Built responsive layouts using media queries.
- Used modern typography and color schemes.
- Practiced browser developer tools for debugging.
